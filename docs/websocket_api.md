# 通用报文格式（JOSN）
------
## 请求
| 参数 | 必选 | 类型 | 说明 |
| :----- | :-----: | :----- | :----- |
| token | true | string | 操作标识 |
| cmd   | true | number | 指令id |

## 返回
| 返回字段 | 字段类型 | 说明 |
| :----- | :----- | :----- |
| token | string | 操作标识，与请求包一致 |
| cmd   | number | 指令id，与请求包一致 |
| code  | number | 返回代码. 0:成功, -1:无效格式, -2:无效cmd,-3，无效token, -4，无效指令参数 |

## 备注
无

------

| 参数 | 必选 | 类型 | 说明 |

### ap列表内容
| 名称 | 类型 | 说明 |
| :----- | :-----: | :----- | :----- |
| ssid | string | ap ssid |
| auth | number | 授权方式。<br>[0]: open<br>[1]: WEP<br>[2]: WPA_PSK<br>[3]: WPA2_PSK<br>[4]: WPA_WPA2_PSK<br>[5]: WPA2_ENTERPRISE<br>[6]: WPA3_PSK<br>[7]: WPA2_WPA3_PSK<br>其它：未定义|
| rssi | number | 信号质量 |
