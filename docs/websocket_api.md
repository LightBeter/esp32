#通用报文格式（JOSN）
------
## 请求
| 参数 | 必选 | 类型 | 说明 |
| :----- | :-----: | :----- | :----- |
| token | true | string | 操作标识 |
| cmd   | true | number | 指令id |

## 返回
| 返回字段 | 字段类型 | 说明 |
| :----- | :----- | :----- |
| token | string | 操作标识，与请求包一致 |
| cmd   | number | 指令id，与请求包一致 |
| code  | number | 返回代码. 0:成功, -1:无效格式, -2:无效cmd,-3，无效token, -4，无效指令参数 |

## 备注
无

#读出指定小时时间表[20]
------
## 请求
| 参数 | 必选 | 类型 | 说明 |
| :----- | :-----: | :----- | :----- |
| hour | true | number | 需要读取的时间范围，范围：0 – 23 |

## 返回
| 返回字段 | 字段类型 | 说明 |
| :----- | :----- | :----- |
| list | array | 使能的时间点配置列表 |

## 备注
每次只能读取某小时内的时间点列表，时间范围为该小时间内的hour:00:00 - hour:59：59内

------
#写入指定小时时间表[21]
------
## 请求
| 参数 | 必选 | 类型 | 说明 |
| :----- | :-----: | :----- | :----- |
| hour | true | number | 需要写入的时间范围，范围：0 – 23 |
| list | true | array | 使能的时间点配置列表，不在列表内的其它时间点将设置为禁用 |

## 返回
| 返回字段 | 字段类型 | 说明 |
| :----- | :----- | :----- |
| NULL | NULL | NULL |

## 备注
每次只能写入某小时内的时间点列表，时间范围为该小时间内的hour:00:00 - hour:59：59内

#编辑时间点[23]
------
## 请求
| 参数 | 必选 | 类型 | 说明 |
| :----- | :-----: | :----- | :----- |
| tp | true | number | 从00:00算取的分钟数，范围：0 - 1439 |
| en | true | bool | 使能标记，false - 禁用（删除），true - 使用 |
| out | true | number[7] | en[true]有效，[0]-white，[1]-dark blue，[2]-blue， [3]-red，[4]-green，[5]-uv405，[6]-uv415。 值有效范围：0 – 100 |

## 返回
| 返回字段 | 字段类型 | 说明 |
| :----- | :----- | :----- |
| NULL | NULL | NULL |

## 备注
可用作新增/编辑/删除时间点
